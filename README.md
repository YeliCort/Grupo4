# Google Store

## 📌 Descripción
Este proyecto es una práctica del bootcamp donde recreamos una página estilo Google Store. El objetivo es aprender a maquetar una web con HTML y CSS.

## 🎯 Objetivo del proyecto
Google Store va a incorporar dos nuevos productos y nos ha pedido incorporarlos en la página existente. Ya nos han entregado el diseño pero está en formato jpg así como el sticker sheet. Nuestro trabajo consistirá en hacer los wireframes de baja fidelidad y las maquetas en figma y luego desarrollar la web con HTML5 y CSS3.

## 💻 Tecnologías utilizadas
- HTML5
- CSS3

## 🛠️ Herramientas
- Figma
- Visual Studio Code
  
## 📦 Instalación
